# prefectureDestroyer
Marre de rester scotché devant son écran à rafraîchir la page de prise de rdv pour votre titre de séjour? 
Voici la solution, un simple script python avec la librairie selenium qui fait le tout pour vous.

You're tired of refreshing away the pages of booking for your residency permit card? 
Here is a simple python script done with the library selenium that does it for you.

## Instructions 

    Installer Python 3.10.2 sur Windows

    Installer VSCode avec l'extension Python
    Extraire le .zip dans un dossier
    Ouvrir VS Code, ouvrir le dossier
    Dans le terminal VS Code, exécuter :
        pip install -r requirements.txt
    Ouvrir le fichier de script .py avec VS Code
    Lancer le script avec VS Code. 

PS: Il faut renseigner le captcha toutes les 15-30 minutes à peu près
